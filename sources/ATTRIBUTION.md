# SRD attribution

This repository includes `SRD_CC_v5.2.1.pdf` as the sole approved D&D rules source for Archie v1.0.0.

The System Reference Document 5.2.1 is made available by Wizards of the Coast under the Creative Commons Attribution 4.0 International license (CC-BY-4.0). Consult the source document itself for its complete attribution statement and notices.

Archie's source manifest pins the exact PDF by SHA-256 so an altered or substituted document cannot silently become authoritative.
